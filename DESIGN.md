# DESIGN — Invoice Keeper

Наборная гранка. Предмет — шрифт, не лист. Холодный камень `#e4e2dc`, на нём светлый набор `#f4f3ef`, чернила `#161615`. Линейка гроссбуха на месте: три валюты, волосяные правила, слипы ниже 720px. Без зерна, пергамента, волнистого подчёркивания, поворота и тени.

| Токен | Значение | Куда |
|---|---|---|
| `--paper` | `#e4e2dc` | фон, камень |
| `--paper-2` | `#f4f3ef` | набор: формы, таблицы, диалоги |
| `--ink` | `#161615` | текст, рамки, заливка главной кнопки |
| `--ink-soft` | `#5e5c56` | вторичный текст, пустая валюта |
| `--rule` | `#c8c4bc` | волосяная линейка, 1px |
| `--overdue` | `#9c2f2f` | просроченная сумма и разрушительное подтверждение |
| `--paid` | `#24564a` | плоский ярлык `.stamp` |

Красный больше нигде: не в wordmark, не в тосте, не в баннере. «Оплачено» — плоская волосяная рамка `.stamp`, без поворота и без заливки. Пустая валюта — тире `--ink-soft`.

Одна ссылка в `frontend/index.html`. IBM Plex Mono — все суммы, даты, коды валют и `.num` (`lining-nums tabular-nums`). Source Sans 3 — подписи, навигация, кнопки, основной текст, русские заголовки. Fraunces (`font-serif`) — только латинский wordmark «Invoice Keeper». Не заголовки страниц, не суммы, не кириллица.

Радиус 2px. Кнопки и поля не ниже 44px. Ниже 720px нет горизонтального скролла: строка — `.slip`. Варианты `desk:` и `hand:`.

Классы те же: `.num`, `.btn`, `.btn-primary`, `.btn-ghost`, `.btn-danger`, `.field`, `.label`, `.sheet`, `.ledger`, `.stamp`, `.overdue-ink`, `.balance`, `.balance-col`, `.balance-kicker`, `.balance-num`, `.balance-empty`, `.slip`, `.slip-row`, `.sum-line`.
